## 📱 What This App Does

The FloodSense Citizen App puts a fully functional disaster-response toolkit in every Malaysian's pocket. It is designed for **zero-training usability** and features a complete bilingual ecosystem (Bahasa Melayu / English) spanning Citizen, Volunteer, and Government Officer interfaces. Language changes seamlessly toggle dynamically across all dashboards, AI assistants, and system alerts to ensure complete clarity in emergency situations.

## ✨ Features

### 🆘 SOS Emergency Alert
- One-tap SOS broadcast to Firebase, instantly visible to the command dashboard
- Captures address, head count, floor level, and vulnerable group tags (infant / wheelchair / elderly / oxygen)
- Auto-assigned urgency level (CRITICAL → LOW) fed to the Coordinator Agent for volunteer dispatch

### 👤 Household Profile + MyKad OCR
- Stores household member details locally and in Firestore for pre-registration before flood season
- **Gemini Vision OCR**: tap to scan a MyKad — auto-extracts full name, IC number, address, DOB, gender, and nationality using `gemini-2.0-flash`
- Extracted data one-tap fills the profile form

### 📋 Flood SOP / Bantuan Guide
- Structured flood preparedness and emergency guides in Malay & English
- Covers: before, during, and after flood procedures; JKM aid eligibility; contaminated water safety; insurance claims

### 🏠 Damage Claim (Tuntutan Kerosakan)
- Room-by-room AI damage assessment powered by Gemini Vision
- Each assessed item is classified by NADMA damage band (A / B / C) and severity (1–5)
- Generates a printable **PDF claim form** (HTML → print dialog) pre-filled with applicant details, itemised damage table, and JKM-compliant layout
- Claim saved to Firestore for officer review

### 🤝 Volunteer Portal
- Register as an APM / NADMA volunteer with skills, vehicle type, and capacity
- Real-time mission offer notifications via Firestore stream
- Accept / Decline rescue missions with one tap → auto-updates incident status to `DISPATCHED`
- View completed missions and generate a **digital service certificate** (verifiable ID + QR placeholder)
- Standing consent toggle to pause/resume receiving mission offers

### 🏫 PPS Kiosk Mode (Relief Centre Self-Registration)
- Designed for **tablets** at Pusat Pemindahan Sementara (evacuation centres)
- Large text, large touch targets — accessible to elderly evacuees
- 4-language self-registration flow: Language → Identity → Family Size → Confirm → Done
- Special needs tagging (wheelchair / oxygen / dialysis / infant etc.)
- Generates a unique registration receipt ID saved to Firestore

## ⚡ Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install/windows/mobile) ≥ 3.3.0 added to `PATH`
- Android Studio with at least one AVD (emulator) configured
- A Firebase project (`floodsense-app`) with Firestore, Auth, Storage, and Messaging enabled

### 1. Install dependencies

```powershell
cd FloodSense/mobile
flutter pub get
```

### 2. Configure Firebase

Run FlutterFire CLI to generate real `firebase_options.dart` and download `google-services.json`:

```powershell
# One-time install
dart pub global activate flutterfire_cli

# Link to your Firebase project
flutterfire configure --project=floodsense-app
```

> ⚠️ The app will crash on startup if `firebase_options.dart` still contains the placeholder `appId`.

### 3. Set your Gemini API key

The MyKad OCR and damage assessment features use Gemini. Pass the key at build time:

```powershell
flutter run --dart-define=GEMINI_API_KEY=your_key_here
```

Get a free key at [aistudio.google.com](https://aistudio.google.com/app/apikey).

### 4. Launch the emulator and run

```powershell
# Start an Android emulator from Android Studio first, then:
flutter run
```

Hot reload with `r`, hot restart with `R`, quit with `q`.

## 🔑 Environment Variables

No `.env` file is needed — all runtime config is passed via `--dart-define`:

| Variable | Purpose |
|----------|---------|
| `GEMINI_API_KEY` | MyKad OCR + AI damage assessment (Gemini 2.0 Flash) |

Firebase config is baked in at build time via `firebase_options.dart` (generated by `flutterfire configure`).
